# eventra-app
Aplicación móvil Eventra - gestión de eventos deportivos con arquitectura de microservicios.

# Eventra App

Eventra App es una aplicación móvil orientada a la comunidad runner en Colombia, diseñada para facilitar la organización, gestión y participación en eventos deportivos y carreras.

La plataforma permite a corredores descubrir eventos, gestionar inscripciones y consultar información relevante sobre competencias, recorridos y resultados.

---

# Objetivo del proyecto

El objetivo principal de Eventra App es centralizar la experiencia de los runners en una sola plataforma, brindando herramientas modernas para la administración de eventos deportivos y la interacción entre organizadores y participantes.

---

# Funcionalidades principales

- Registro e inicio de sesión de usuarios
- Gestión de perfiles de corredores
- Publicación y administración de eventos
- Inscripción a carreras y eventos deportivos
- Consulta de información detallada de eventos
- Visualización de recorridos y horarios
- Gestión de participantes
- Consumo de API REST
- Integración y pruebas mediante Postman
- Navegación entre pantallas optimizada para dispositivos móviles
